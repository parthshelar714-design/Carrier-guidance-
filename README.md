# Carrier-guidance-
🎓 Career Guidance Website

A simple and helpful Career Guidance Website designed for students to explore different career paths, study materials, and future opportunities.

---

🌟 Features

- 📚 Career options after 10th, 12th, Diploma
- 💻 Computer Engineering career paths
- 📝 Study materials and notes
- 📊 Career comparison
- 🎯 Simple and student-friendly design
- 📱 Mobile responsive

---

🖥️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages (for hosting)

---

---

🎯 Purpose

This website helps students choose the right career path by providing:

- Career information
- Required skills
- Salary details
- Study roadmap
